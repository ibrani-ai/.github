# Ibrani.AI — AI-Powered Hebrew Speech Tools

**[Ibrani.AI](https://www.ibrani.ai)** builds AI-powered tools for practicing and measuring spoken Hebrew.

Whether you're a new immigrant (oleh chadash), a heritage speaker, or preparing for exams — Ibrani helps you speak Hebrew with confidence.

### [Hebrew Speech Assessment](https://app.ibrani.ai)
AI-driven evaluation of spoken Hebrew. Get real-time feedback on pronunciation, fluency, and accuracy.

### [Bagrut Exam Simulation](https://bagrut.ibrani.ai)
